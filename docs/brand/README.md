# Sowgatly logo

Chosen concept: **3 · Doly** (filled gift box) from `preview.html`.

Master files live in `public/img/logo/`:

| File | Use |
|---|---|
| `logo-square.svg` | Full-bleed app icon (iOS, Android launcher, `logo.png`) |
| `logo-rounded.svg` | Rounded icon (favicons, UI) |
| `logo-circle.svg` | Circular avatar |
| `logo-mark.svg` | Gradient gift on transparent (light backgrounds) |
| `logo-mark-white.svg` | White gift on transparent (brand or dark backgrounds) |

Colours: gradient `#FF6A00 → #FF2A00` at 135°, solid fallback `#FF4A00`.
Wordmark: Poppins SemiBold, lower-case "sowgatly" (`public/fonts/Poppins`).
All PNG/ICO sizes in `public/img/logo/` were rendered from these SVGs; the mobile app
carries the same files in `assets/img/logo/` plus `assets/icon.png`,
`assets/adaptive-icon*.png` and `assets/splash.png`.

`brand_logo.png` is a personal mark of the developer, not the Sowgatly logo, and was left as is.
